Meu projeto é um site de vendas de beats (Trap, Funk e outros estilos), desenvolvido como um teste de front-end e ideias criativas. Ele conta com uma interface bonita, caprichada e interativa, pensada para oferecer uma experiência agradável aos usuários.

Além da vitrine de beats, o site também disponibiliza downloads de drumkits e livros de mixagem, ampliando as possibilidades para produtores musicais. Todo o projeto foi versionado no GitHub, ficando hospedado de forma online para qualquer pessoa acessar.
